Welcome to the Sprint Project

This basic HTML page serves as the foundation for testing our Git and GitHub workflow.

This repository showcases a responsive web application built to demonstrate a complete end-to-end Git and GitHub collaborative workflow. The project features a structured HTML5 layout with an external CSS stylesheet, including a custom flexbox navigation bar and a sticky footer pinned to the bottom of the viewport. Beyond the code, the repository serves as a practical demonstration of modern software development infrastructure, utilizing GitHub Projects and Issues for task tracking, enforcing a strict feature-branching strategy with pull request automation, and demonstrating local conflict resolution techniques.
